# Memora Frontend

Phase 1 builds the frontend foundation for Memora using Next.js, TypeScript,
Tailwind CSS, and shadcn/ui.

This app does not connect to backend, storage, ingestion, AI, embedding, search,
or RAG services yet.

## Phase 1 Routes

- `/` dashboard
- `/spaces` and `/spaces/[slug]`
- `/library` and `/library/[slug]`
- `/save`
- `/search`
- `/profile`
- `/settings`

## Scripts

```bash
npm run dev
npm run lint
npm run build
```
