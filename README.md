# Memora

Memora is an AI-powered multimodal personal knowledge platform.

Phase 1 is focused only on the frontend foundation. The Next.js app lives in
`frontend/` so future backend, AI, ingestion, and infrastructure services can be
added alongside it without reshaping the repository.

## Frontend

```bash
cd frontend
npm run dev
```

Phase 1 is complete when `npm run lint` and `npm run build` pass inside
`frontend/`. All product data is mock/local UI data only.
