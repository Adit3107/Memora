# Memora

Memora is an AI-powered multimodal personal knowledge platform.

Tagline:

```text
Your second memory.
```

The V1 learning architecture is:

```text
Save content
   -> extract and understand content
   -> clean
   -> chunk
   -> generate embeddings
   -> store in PostgreSQL + pgvector
```

## Architecture

```text
Next.js
   |
   v
Go API
   |
   +------ PostgreSQL + pgvector
   |
   +------ S3
   |
   +------ Python AI Service
              |
              +-- Embeddings
              +-- OCR/processing support
              +-- Future AI services
```

The frontend calls only the Go backend. Python is an internal service used by Go
for specialized AI and extraction work.

```text
Next.js -> Go -> Python
```

Never:

```text
Next.js -> Python
```

## Current Phase

Phase 5 adds vectorized knowledge:

- YouTube transcripts become timestamp-aware chunks with embeddings.
- Documents become page-aware chunks with embeddings.
- Embeddings are generated by the Python AI service.
- Go validates and stores vectors in PostgreSQL using pgvector.

Search and RAG are later phases. Phase 5 only guarantees that vectorized chunks
exist and are ready to be retrieved later.

## Services

Run the backend:

```powershell
cd backend
go run ./cmd/server
```

Run the AI service:

```powershell
cd ai-service
.\.venv\Scripts\Activate.ps1
uvicorn app.main:app --reload --port 8001
```

Run the frontend:

```powershell
cd frontend
npm run dev
```
